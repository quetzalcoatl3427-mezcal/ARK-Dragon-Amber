ARK Dragon Amber — proyecto Android inicial (v0.1)
===================================================
Este proyecto envuelve el detector de ámbar en una Activity Android con WebView.

Incluye:
- Pantalla Android vertical.
- Detector con cuatro coordenadas iniciales y alta manual de puntos.
- Distancia plana aproximada en unidades de coordenadas.

No incluye aún:
- APK compilada (el entorno actual no tiene Android SDK/Gradle instalado).
- Lectura automática del chat de ARK.
- Ventana flotante.
- Good Console, teleport, administración de FreeARK o modificación del juego.
Esas funciones requieren investigación e integración separada; no deben considerarse implementadas.

Para compilar:
- Abrir la carpeta en Android Studio reciente con Android SDK instalado.
- Sincronizar Gradle y usar Build > Build APK(s).
